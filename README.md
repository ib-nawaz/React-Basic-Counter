# 🚀 React Counter App

My first basic React project, built to learn the fundamentals of React and state management.

## ✨ Features
- ➕ Increment the counter
- ➖ Decrement the counter
- 🚫 Prevents negative numbers
- ⚛️ Uses React `useState` Hook
- 💬 Displays a warning message when decrementing below zero

## 🛠️ Technologies Used
- React.js
- JavaScript
- HTML
- CSS

## 📸 About the Project
This project helped me understand React components, event handling, state management, and conditional logic.



## 🎯 Learning Goal
This is my first React project as I begin my journey into frontend development.
